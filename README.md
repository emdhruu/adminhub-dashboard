# AdminHub — Production-Ready Admin Dashboard

A responsive, production-grade Admin Dashboard built with Next.js App Router, TypeScript, Tailwind CSS, shadcn/ui, TanStack Query, and Redux Toolkit. Built as part of the Frontend Developer Round 2 Practical Assignment based on the approved Figma UI/UX design specifications.

## Local Setup & Installation Instructions

### Prerequisites
- Node.js 18.18+ or 20+
- npm, pnpm, or yarn

### Steps

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/your-username/adminhub-dashboard.git](https://github.com/your-username/adminhub-dashboard.git)
   cd adminhub-dashboard```

2. **Install dependencies:**
    ```npm install```

3. **Run the development server:**
    ```npm run dev```
